# 后续移除临时截屏开关

设置 → 保护 → **允许截屏（临时）**。默认关闭，设置保存于本机。开启后仅在应用已解锁且位于前台时解除 Android 截屏/录屏限制。锁定、失焦、后台时恢复限制；Android 13 及以上仍禁用最近任务截图。

## 删除清单

全局搜索 **TEMP_SCREENSHOT_TOGGLE**、**allowScreenshots** 和 **setScreenshotAllowed**。仅移除下列临时代码：

1. 设置页移除标记的开关行。
2. 从 AppPreferences 移除 allowScreenshots 字段，以及构造参数、copyWith 和 JSON 编解码条目。旧设置文件中的多余 JSON 键会被忽略，账号无需迁移。
3. 删除 TemporaryScreenshotOverride 文件，并从 JiaoApp 移除其导入、实例、初始化和释放调用。
4. 在 Android MainActivity 移除 setScreenshotAllowed 分支、captureResumed 和标记的 onResume / onPause。onWindowFocusChanged 只移除标记的那一行，保留剪贴板清理。**保留 onCreate 原有 FLAG_SECURE 和 setRecentsScreenshotEnabled(false)。**
5. 移除临时截屏开关的两个测试，保留同文件中的滑动测试。运行测试并重新打包。
