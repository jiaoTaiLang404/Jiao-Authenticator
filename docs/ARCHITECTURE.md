# 架构取舍

日期：2026-11-10；状态：首版采用。

## 本地架构

ChangeNotifier + 构造注入；不引入数据库、服务端或大型状态框架。算法、文件、备份、仓储、锁定与 UI 分离。生产入口注入真实安全存储和系统认证；替身仅用于测试。

TOTP 由当前 Unix 毫秒换算计数器，8 字节大端输入 HMAC。界面定时器只刷新，不累计算法时间。Next 边界为 `(seconds ~/ period + 1) * period`，保留算法/位数/周期。后台停刷，返回立即重算。

## 数据与锁定

写入串行，持久化成功后才发布状态。去重身份为规范化密钥 + 算法 + 位数 + 周期，最多 2000 个账号。读取失败不写空集合；显式恢复写独立 recovery 命名空间，保留 primary，重启优先读取恢复库。

默认冷启动锁定，系统指纹或设备凭据验证；关闭应用锁也需新验证。inactive 立即遮挡，hidden/paused 开始 30 秒计时。会话标识阻止迟到的结果重新填充锁定界面。锁定移除 UI 引用，但 Dart 无法保证所有不可变字符串及 GC 副本的物理擦除。

## 加密备份 v1

| 偏移 | 长度 | 字段 |
|---|---|---|
| 0 | 8 | ASCII `JIAOAUTH` |
| 8 | 1 | 版本 1 |
| 9 | 16 | 随机 salt |
| 25 | 12 | 随机 nonce |
| 37 | 16 | GCM tag |
| 53 | 剩余 | 密文 |

PBKDF2-HMAC-SHA256 固定 600000 次派生 32 字节密钥；AES-256-GCM 的 AAD 为前 37 字节。每次新盐和 nonce，口令按原样处理，不 trim 或 Unicode 规范化。固定成本避免文件头控制 KDF 开销。后台 isolate 完成派生/加解密，完整模型校验后才允许预览并一次提交。

文件上限 10 MB，二维码图片 20 MB；系统保存器只接收密文，不产生明文临时备份。图片及选择器缓存用后清理。

## Android 边界

原生 Activity 配置 FLAG_SECURE 和最近任务遮挡；剪贴板有敏感标记和随机所有权 ID，只清理仍属于本次复制的内容。旧/新备份规则排除应用数据，跨设备恢复使用显式加密备份。

正式 manifest 移除网络、广告 ID 与广泛媒体/存储权限；识别模型随包分发。构建工具下载依赖与运行时联网是不同边界，本机临时构建缓存代理不随应用分发。
